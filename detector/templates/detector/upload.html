What the file needs

  • One row per transaction, with a 0/1 fraud label column named Class, isFraud or is_fraud.
  • Transaction features, such as Amount, V1…V28, merchant category or channel.
  • For behavioural signals and the graph model: a timestamp and IDs for account, device, IP address and merchant. Common names like account_id, device_id, ip_address and merchant_id are picked up automatically.
  • At least 20 fraudulent rows so the test set is meaningful.

Files without labels (for example a Kaggle sample_submission.csv) can't be trained or scored, because there is nothing to learn from or compare against.
